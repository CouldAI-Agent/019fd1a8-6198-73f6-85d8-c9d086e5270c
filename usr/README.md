# Guilt-Free Bakery App

A cross-platform Flutter application built to showcase and sell healthy, guilt-free bakery products. This project was born out of a fundraising initiative to support flood victims in 2025 and has now evolved into a mission to provide sugar-free, gluten-free, and low-carb options for health-conscious consumers.

## Features
*   **Home Dashboard**: Featured products and brand overview.
*   **Menu Catalog**: Browse sweet and savory bakery items with dietary tags (sugar-free, low-carb, gluten-free).
*   **About Us Story**: The journey from fundraising stalls to a sustainable, healthy bakery business.
*   **Cart System**: Mockup for e-commerce integration.

## Tech Stack
*   **Framework**: Flutter
*   **Language**: Dart
*   **Platforms**: iOS, Android, Web, Desktop

## Setup & Run
1. Ensure Flutter is installed on your machine.
2. Clone this repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to launch the app on your connected device or emulator.
